개인정보처리방침

시간조각 · 시행일 2026년 10월 30일

시간조각(이하 "이 앱")은 하루를 시간 단위로 기록하는 개인이 운영하는 웹 앱이에요. 꼭 필요한 정보만 받고, 광고나 분석 도구는 쓰지 않아요. 아래에서 어떤 정보를 어떻게 다루는지 설명해요.

1. 받는 정보

구분항목받는 때
구글 로그인 정보이메일 주소, 계정 고유 식별자(구글이 제공하는 기본 프로필 정보)"Google로 계속하기"로 로그인할 때
직접 입력한 기록날짜별 계획·실제 시간 기록, 분류 이름·색, 메모, 고정 루틴, 글꼴·화면 모드 같은 설정로그인한 상태에서 기록을 저장할 때

로그인 없이 "이 기기에서만 쓰기"를 고르면 기록은 내 기기의 브라우저에만 저장되고, 운영자나 서버로 전송되지 않아요.

이 앱은 구글 계정에서 위 정보 외의 데이터(연락처, 드라이브, 캘린더, 메일 등)에 접근하지 않아요.

2. 이용 목적

  • 로그인한 사람이 누구인지 확인하고, 그 사람의 기록만 보여 주기 위해서요.
  • 여러 기기(폰, 컴퓨터)에서 같은 기록을 볼 수 있도록 동기화하기 위해서요.

받은 정보는 위 목적 외에 사용하지 않고, 광고·마케팅·프로파일링·판매에 쓰지 않아요.

3. 보관 장소와 기간

  • 클라우드 데이터베이스: 로그인한 사용자의 기록과 설정은 Supabase의 데이터베이스에 저장돼요. 각 사용자는 자기 데이터만 읽고 쓸 수 있도록 접근이 제한돼 있어요.
  • 내 기기: 빠른 표시와 오프라인 사용을 위해 브라우저 저장소(localStorage)에도 사본이 저장돼요. 로그아웃하면 이 사본은 지워져요.
  • 보관 기간: 이용자가 삭제를 요청하거나 직접 삭제할 때까지 보관해요.

4. 제3자 제공과 처리 위탁

이용자의 정보를 제3자에게 판매하거나 제공하지 않아요. 서비스 제공에 필요한 아래 업체의 인프라를 사용해요.

업체역할
Supabase로그인 처리와 기록 데이터 저장
Google구글 계정 로그인 인증
GitHub (GitHub Pages)앱 파일을 보여 주는 호스팅 (기록은 저장하지 않음)

이 앱이 구글 계정에서 받은 정보를 사용하고 다른 곳으로 전달하는 일은 Google API 서비스 사용자 데이터 정책(제한된 사용 요건 포함)을 따라요.

5. 쿠키와 분석 도구

로그인 상태를 유지하는 데 필요한 정보(세션)를 브라우저 저장소에 저장해요. 광고용 쿠키나 방문 분석 도구(예: 구글 애널리틱스)는 쓰지 않아요. 화면 글꼴은 Google Fonts에서 불러올 수 있어요.

6. 이용자의 권리와 삭제 방법

  • 직접 삭제: 앱 설정 → 계정 → 클라우드 기록 모두 삭제를 누르면 계정에 저장된 기록과 설정이 지워져요.
  • 하루 기록 삭제: 각 날짜 화면의 "초기화" 버튼으로 그날의 계획이나 실제 기록을 지울 수 있어요.
  • 계정 정보 삭제 요청: 로그인 정보(이메일 등)까지 완전히 삭제하려면 아래 문의처로 요청해 주세요. 확인되는 대로 삭제해요.
  • 열람·정정: 기록은 앱에서 언제든 직접 보고 고칠 수 있어요. 백업 기능으로 내려받을 수도 있어요.

7. 보안

  • 모든 통신은 HTTPS로 암호화돼요.
  • 데이터베이스에는 사용자별 접근 제한(행 단위 보안)이 적용돼, 로그인한 본인만 자기 기록에 접근할 수 있어요.
  • 구글 비밀번호는 이 앱이 받지도 저장하지도 않아요.
